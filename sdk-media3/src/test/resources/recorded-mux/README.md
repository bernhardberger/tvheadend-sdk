# JVM reader fixtures

The MPEG-2 audio and AC-3 payloads are byte-identical copies of the first packets
in Android test channel 4. They preserve their live HTSP packet boundaries. The
AAC payload is one synthetic AAC-LC frame with an ADTS header, generated by
Debian FFmpeg 7.1.5. None of the fixtures contain endpoint, credential,
subscription, programme, or server metadata.

| `mpeg-audio.bin` | 576 | `b99e3427331676dc0aac71bcd212494768fb6d608be1ee0d128726bcf9ae6d97` |
| `ac3.bin` | 1536 | `3ec44cd72eac63889ed50b4859ed5788c2f1613121eb72130a54e68f3b992bfc` |

The AAC fixture was generated and reduced to one encoded packet with:

```shell
ffmpeg -f lavfi -i 'sine=frequency=1000:sample_rate=48000:duration=0.021333333' \
  -frames:a 1 -c:a aac -profile:a aac_low -b:a 96k -f adts aac-adts-full.bin
ffmpeg -i aac-adts-full.bin -frames:a 1 -c:a copy -f adts aac-adts.bin
```
