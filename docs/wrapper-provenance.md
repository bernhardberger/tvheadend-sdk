# Gradle wrapper provenance

## Version-neutral launcher and wrapper JAR

The launcher scripts and wrapper JAR were generated by Gradle 9.8.1 with
`./gradlew wrapper --gradle-version 9.8.1 --distribution-type bin
--gradle-distribution-sha256-sum dce76f55f8e251a3a1f130eb120f30b3d271de2b76c9b0729d316b5a1b6dc01f`
(run twice so the wrapper regenerates itself):

| Path | SHA-256 |
|---|---|
| `gradlew` | `a5a5c199ba02189ae8c46a334223371a20599d9c298ef65e7540ede4a3f72d59` |
| `gradlew.bat` | `f17917f8dbe61182b149273ee78090fec1197442c3f38276af907bfa5190db16` |
| `gradle/wrapper/gradle-wrapper.jar` | `3b8a25775a69158b5ad2b1d17a80a88dc7b40a352a73eb27d06c612a7ce68e98` |

The JAR digest matches the official
`https://services.gradle.org/distributions/gradle-9.8.1-wrapper.jar.sha256`.
`gradlew.bat` keeps Gradle's generated CRLF line endings: `.gitattributes`
declares `*.bat text eol=crlf`, so Git stores it normalized to LF and checks it
out with CRLF. The listed digest is of the checked-out CRLF file, which is
byte-identical to the `gradlew.bat` that the Gradle 9.8.1 distribution
generates with the same `wrapper` arguments in an empty directory. These bytes do not
prove or identify the downloaded Gradle distribution.

## Official distribution pin

`gradle-wrapper.properties` separately pins the official URL
`https://services.gradle.org/distributions/gradle-9.8.1-bin.zip`, enables URL
validation, and records distribution SHA-256
`dce76f55f8e251a3a1f130eb120f30b3d271de2b76c9b0729d316b5a1b6dc01f`.
CI verifies these authorities before invoking the wrapper.
